Features

Everything you need to remote-control your phone from your computer.

👁

Screen mirroring

See your phone screen live on your desktop with low-latency JPEG frames.

👇

Remote input

Tap, swipe, type text, and press navigation keys from your desktop.

🏡

App launcher

Browse installed apps and launch them remotely with a double-click.

📉

Pairing codes

6-digit codes with phone-side consent — nothing connects without your approval.

📟

File transfer

Push and pull files between desktop and phone over the secure tunnel.

📅

Clipboard sync

Copy on one device, paste on the other.

How it works

Three steps from install to full control.

1

Install the agent

Download the APK on your phone, install it, and enter your computer's LAN IP as the hub address.

2

Pair with code

Start the agent to get a 6-digit pairing code, type it into the desktop app, and accept on your phone.

3

Take control

Mirror the screen, tap, swipe, type, launch apps — everything works in real time.
